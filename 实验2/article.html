我的第一篇 HTML 学习笔记

发布时间：2026年9月29日 · 分类：HTML · 阅读约 3 分钟

HTML 就像盖房子的骨架，负责搭出页面的结构；CSS 则是装修，负责让页面变漂亮。两者配合，才能做出既结构清晰又好看的网页。

一、页面长什么样：三大块

一个标准页面通常分成三部分，用语义化标签写出来，代码一眼就懂：

  • <header>：页头（标题、导航）
  • <main>：主体（文章、侧边栏）
  • <footer>：页脚（版权信息）

二、head 与 body 的区别

这是初学者最容易混的地方，记住一句就行：

<head> 里放“看不见的信息”（编码、标题、样式）；<body> 里放“看得见的内容”（文字、图片、链接）。

比如下面这段，就是设置字符编码和标签页标题：

<meta charset="UTF-8">
<title>我的博客</title>

三、语义化标签的好处

别全用 <div>，该用啥就用啥，好处很多：

  1. 结构清晰，自己和别人都好读
  2. 对搜索引擎、读屏软件更友好
  3. 配合 CSS 写样式时，类名更少、更好维护

常用的语义化标签：header / nav / main / section / article / aside / footer。

四、下一步学什么

结构会了，下一步就是 CSS：盒模型、flex 布局、样式重置、组件化……也就是实验2要做的事。继续加油！
