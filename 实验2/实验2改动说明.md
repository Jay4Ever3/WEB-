## 二、具体改了哪些内容

### 改动 1：样式重置 + 初始化（实验2 目的①）
- **新建 `reset.css`**：用自己写的 CSS 覆盖浏览器默认样式（body 默认外边距、列表缩进与项目符号、图片行内空隙、表格双线等），让所有页面从“统一、可控”的起点开始。
- **关键点**：实验2 **明确禁止**用 `* { margin:0; padding:0; }` 这种“全清”写法（会把标题/段落本该有的间距也清掉）。本工程只精确清除会捣乱的默认样式。
- **新建 `base.css`**：在 reset 之上设定全站统一的变量（主题色/圆角）、字体、行高、标题、链接、聚焦描边。

### 改动 2：样式表组件化（实验2 目的②）
- **新建 `common.css`**：把“每个页面都有的部分”抽成公共组件——页头、导航（含二级菜单）、左右双栏布局、卡片、表格、表单、页脚。
- **复用方式**：`<head>` 里按序外链 `reset → base → common`。主页和内容页引用**同一份**，改一处全站生效。这就是“组件化”的核心思想。
- 顺手练了实验2【自主拓展】：`CSS 变量`（`:root` 里定义，全站换色只改一处）和`伪元素`（`.site-header::before/::after` 画装饰圆、导航下划线）。

### 改动 3：新建“博客内容页”（实验2 目的③，实验内容第2条）
- **新建 `article.html`**：复用主页的页头/导航/页脚（HTML 直接复制），正文是一篇完整文章，排版由 `article.css` 负责（标题、段落、带项目符号的列表、引用块、行内代码/代码块、返回主页按钮）。
- **新建 `article.css`**：只放内容页“自己独有”的样式，不与 common 重复。

### 改动 4：页面自适应（实验2 选做）
- **新建 `media-query.css`**：用 `@media (max-width: 768px)` 实现窄屏适配：
  1. 左右双栏 → 上下单栏（flex 主轴改 `column`）；
  2. 桌面横向导航隐藏，改用 `<details>` 折叠菜单（`summary` 写“菜单”），纯 HTML 实现、无需 JS；
  3. 小屏标题缩字号、文章内边距收窄。

## 三、HTML 头部引用顺序（重点考点）

```html
<link rel="stylesheet" href="css/reset.css">     <!-- 1. 先重置 -->
<link rel="stylesheet" href="css/base.css">      <!-- 2. 再基础风格 -->
<link rel="stylesheet" href="css/common.css">    <!-- 3. 公共组件 -->
<link rel="stylesheet" href="css/article.css">   <!-- 4. 内容页专属（仅 article.html） -->
<link rel="stylesheet" href="css/media-query.css"><!-- 5. 自适应（放最后，窄屏覆盖前面） -->
```
> 顺序不能乱：后面的样式会“叠”在前面的之上。

## 四、怎么看效果
直接用浏览器打开 `index.html`；点“阅读全文 →”或地址栏进 `article.html` 看内容页。
拖动浏览器窗口变窄（< 768px），可观察双栏变单栏、导航变成“菜单”折叠按钮。
